

## 一、初始化与 `valarray`

1. 初始化列表中的成员初始化顺序由**类中成员的声明顺序**决定，与构造函数参数顺序无关。
    
2. **valarray 类简介：**  
    由 `<valarray>` 头文件支持，用于处理数值序列。
    
    `valarray<int> q_values;  valarray<double> v2(10, 8);  // 8个元素，值均为10`
    
    常用方法：
    
    - `operator[]`
        
    - `size()`
        
    - `sum()`
        
    - `max()`
        
    - `min()`

## 二、私有继承与 has-a 关系

3. 使用**私有继承**时，基类的公有与保护成员都变为派生类的私有成员，派生类不继承基类接口。
    
4. “has-a” 关系的两种实现方式：
    
    - **包含（Composition）**：将一个命名的成员对象添加到类中。
        
    - **私有继承**：将基类对象作为**未命名的继承对象**添加。  
        多个基类继承称为**多重继承（MI）**。
        
5. 私有继承中，基类**没有名称**。若需要访问基类成员，可使用 `this` 指针强制类型转换：
    
    `(Base&)(*this);`
    
6. 一般建议：
    
    - **优先使用“包含”**（composition）来建立 has-a 关系；
        
    - 仅当需要访问基类保护成员或需要重新定义虚函数时使用**私有继承**。 ✅  
        （这一条你加问号是对的，我确认：这句话**是正确的经验法则**）
        
7. 私有继承的声明语法：
    
    `class Student : private std::string { ... };`
    
8. 保护继承（`protected`）是私有继承的一种变体：
    
    `class Student : protected std::string { ... };`
    
    此时基类的公有与保护成员在派生类中都变为**保护成员**。

## 三、多重继承（Multiple Inheritance）

9. 公有多重继承也体现 is-a 关系：
    
    `class SingingWaiter : public Waiter, public Singer { ... };`
    
    注意：每个基类都必须使用 `public`。
    
10. 多重继承中，派生类会**同时继承多个基类的成员**。  
    若这些基类继承自同一基类，会导致**重复继承问题**。  
     解决方案：使用 **虚基类（virtual base class）**，使派生类仅保留一个公共基类副本。
    
11. MI 中将派生类地址赋给基类指针时可能产生**二义性（ambiguous）**。  
    必须通过**显式类型转换**指定要转成的基类类型。
    
12. 当基类是虚基类时，信息不能通过中间类自动传递。  
    → 在多重继承构造函数中，必须**显式调用所需基类构造函数**。**(对虚基类不成立)**
    
13. 若多重继承中未使用虚基类，多个同名成员将导致**二义性**。  
    使用虚基类可统一共享成员，避免歧义。

## 四、类模板（Class Templates）

14. 模板提供**参数化类型**，可将类型名作为参数传递给类或函数：
    

`template <class Type> class Stack { ... };  Stack<int> kernels;`

15. **模板的非类型参数：**
    

`template <class Type, int n>`

- `n` 为非类型参数，可是整型、枚举、引用或指针。
    
- 值必须是**编译期常量表达式**，可提供默认值。
    

16. **递归模板（嵌套模板）**：
    

`ArrayTP<ArrayTP<int, 4>, 10> twodee;`

等价于：

`int twodee[10][4];`

注意：维度顺序与普通数组相反。

17. 模板可以拥有**多个类型参数**：
    

`template <class T1, class T2>`

18. 可以为模板类型参数提供默认值：
    

`template <class T1, class T2 = int>`

✅ 函数模板**不支持**默认模板参数。

19. **显式实例化**与**具体化：**
    

`template class ArrayTP<string, 100>;             // 显式实例化 
`template <> class ClassName<SpecialType> { ... } // 显式具体化 
`template <class T1> class Pair<T1, int> { ... }; // 部分具体化`

20. 模板可用作结构、类或类的成员。  
    → 这是 **STL** 的核心机制之一（见 p.475）。
    
21. 模板可以作为参数，实现多层泛型（见 p.477）。

## 五、模板与友元总结

22. 三种友元形式对模板的处理区别如下：
    

|友元类型|泛型处理方式|特点|
|---|---|---|
|非模板友元|固定类型|所有模板实例共享同一个友元|
|非约束模板友元|可处理任意类型|灵活泛型但不绑定类型|
|约束模板友元|每个类型独立处理|安全且与模板类型严格绑定|

## 六、模板实现规则与注意事项

23. **显式实例化不要放在 .h 文件中**。  
    否则被多处包含时会导致重复定义。
    
24. **模板类的定义与实现不能分离**。  
    因为编译器需要在实例化模板时看到完整定义。  
    ✅ 两种正确做法：
    

- 全部放在 `.h` 文件中；
    
- 或将实现放入 `.tpp` 文件，并在 `.h` 文件末尾 `#include "xxx.tpp"`。
    

---

##  Summary

- 私有继承使基类公有成员变为私有；一般应优先使用“包含”而非私有继承。
    
- 多重继承容易产生二义性，使用**虚基类**可避免重复继承。
    
- 构造函数在 MI 中必须显式指定基类构造。
    
- 类模板必须在一个文件中定义与实现；可使用 `.tpp` 文件引入实现。
    
- 模板实例化不要放在头文件中。
    
- 非类型模板参数与友元模板需掌握基本用法。
