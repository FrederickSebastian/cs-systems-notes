
## 概述

1. 仿函数定义: 仿函数是一种重载了 operator() 的类的对象，可以像函数一样被调用来模拟函数行为。仿函数可以**拥有状态即成员变量**，可以被复制和赋值以及自定义比较、计算、逻辑操作等，还可以**被用作算法函数的参数被传递和调用**，如 std::sort 算法可以接受一个仿函数作为第三个参数，用于指定排序的准则从而提供比普通函数更灵活的行为。
	- 仿函数是可调用对象的一种形式，所有仿函数都是可调用对象，因为它们可以被调用。
	- 可调用对象是一个更广泛的概念，它包括**所有可以被调用的实体，如函数、函数指针、仿函数、Lambda 表达式、成员函数指针**等。

2. 仿函数的实现: 仿函数是通过定义一个类并重载 operator() 来实现的，因此它们是普通的类定义，不需要特殊的头文件支持。operator() 是一个特殊的成员函数，它允许将类或结构体类型的对象当作函数来调用，这个运算符可以接受任意数量和类型的参数，并返回一个值。仿函数的成员变量可以在 operator() 的实现中使用，从而使仿函数能够保持状态。当我们创建一个仿函数的实例并使用 () 调用它时，实际上是在**调用该对象的 operator() 方法**。

## 分类

C++提供了很多仿函数, 主要在`<functional>`.

1. 内建仿函数(Built-in Functor): STL 提供的一些**内置**的仿函数，如 plus, less 等, 它们实现了常见的操作，使用时必须包含`<functional>`头文件，其包含仿函数分类有以下:
	算术类：
	- std::plus：返回两个参数的和。
	- std::minus：返回两个参数的差。
	- std::multiplies：返回两个参数的乘积。
	- std::divides：返回两个参数的商。
	- std::modulus：返回两个参数的模。

	关系类：
	- std::equal_to：检查两个参数是否相等。
	- std::not_equal_to：检查两个参数是否不相等。
	- std::greater：检查第一个参数是否大于第二个参数。
	- std::less：检查第一个参数是否小于第二个参数。
	- std::greater_equal：检查第一个参数是否大于或等于第二个参数。
	- std::less_equal：检查第一个参数是否小于或等于第二个参数。

	逻辑类：
	- std::logical_and：对两个参数进行逻辑与操作。
	- std::logical_or：对两个参数进行逻辑或操作。
	- std::logical_not：对一个参数进行逻辑非操作。

**用法需要得到考察!**

2. 用户自定义仿函数: 不属于 STL 提供的预定义函数对象。其中重载了函数调用运算符 operator() 来实现函数的调用。用户可以根据自己的需求定义一个函数仿函数，将特定的函数封装为函数对象，从而能够在算法中使用: 
```cpp
int add(int a, int b) {
    return a + b;
}

struct AddFunctor {
    int operator()(int a, int b) const {
        return add(a, b);
    }
};

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::vector<int> v2(v.size());

    // 使用函数指针仿函数作为算法的自定义参数
    std::transform(v.begin(), v.end(), v.begin(), v2.begin(), AddFunctor());

    for (int i : v2) {
        std::cout << i << " ";
    } // 输出 2 4 6 8 10

    return 0;
}
```
