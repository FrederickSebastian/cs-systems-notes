# 树形 DP 概述

**树形 DP**，就是在树结构上进行动态规划。

其核心思想是：

> 把一棵树拆成若干棵子树，先计算子节点对应子树的答案，再合并得到当前节点对应子树的答案。

因此，树形 DP 通常以 **深度优先搜索 DFS** 为基础，计算顺序往往对应于二叉树的**后序遍历**. 
**思路**: 通常是总结需要哪些信息, 然后父节点向两个子节点索要所有信息, 然后向前返回.


# 贪心算法的在笔试时的解题套路

1. 实现一个不依靠贪心策略的解法X，可以用最暴力的尝试
2. 脑补出贪心策略A、贪心策略B、贪心策略C...
3. 用解法X和对数器，去验证每一个贪心策略，用实验的方式得知哪个贪心策略正确
4. 不要去纠结贪心策略的证明


**暴力递归**: 暴力递归中递归函数的形式越简单, 可变参数越少越好. 尽量不要出现复杂类型的函数参数, 例如链表
