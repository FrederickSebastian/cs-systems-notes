
## 一、服务器与客户端建立连接的完整过程

TCP服务器建立连接的标准流程：

---

### 1. 创建 socket —— `socket()`

```c
lfd = socket(AF_INET, SOCK_STREAM, 0);
```

作用：

向内核申请一个 TCP 通信端点，生成监听描述符 `lfd`。

参数：

- `AF_INET` ：IPv4协议
    
- `SOCK_STREAM` ：TCP流式连接
    
- `0` ：默认选择TCP协议
    

此时 socket 只是创建出来，还没有地址。

---

### 2. 绑定地址 —— `bind()`

```c
bind(lfd, (struct sockaddr *)&servAddr, sizeof(servAddr));
```

作用：

把 socket 和服务器本机的 IP + 端口号绑定。

例如：

```c
0.0.0.0:9527
```

表示：

- 监听本机所有网卡IP
    
- 使用9527端口接收连接
    

---

#### bind中的 addr 是什么？

`addr` 指的是：

> 本服务器自己的网络地址

即：

```c
servAddr
```

它包含：

```c
struct sockaddr_in servAddr;
```

中的：

|字段|含义|
|---|---|
|sin_family|地址族(AF_INET)|
|sin_port|端口号|
|sin_addr|本机IP地址|

---

#### 为什么必须 bind？

因为操作系统必须知道：

> “哪个程序负责监听哪个端口”

否则客户端连不上来。

---

### 3. 开始监听 —— `listen()`

```c
listen(lfd, MAXLISTEN);
```

作用：

把主动 socket 转换成监听 socket。

开始等待客户端发起连接请求。

参数：

- `lfd`：监听socket
    
- `MAXLISTEN`：等待队列最大长度
    

---

### 4. 接收客户端连接 —— `accept()`

```c
cfd = accept(lfd, (struct sockaddr *)&clinAddr, &clinLen);
```

作用：

从已完成三次握手的连接队列中取出一个客户端连接。

返回：

```c
cfd
```

这是专门和该客户端通信的新socket。

---

## 二、服务器如何找到客户端？

服务器不是主动“寻找”客户端。

而是：

> 客户端主动调用 `connect()` 来连接服务器。

流程如下：

---

### 客户端先发起：

```c
connect()
```

客户端告诉内核：

> 我要连接某个服务器IP:端口

例如：

```c
192.168.1.10:9527
```

---

### 然后服务器收到请求：

监听中的：

```c
listen()
```

发现连接请求进入队列。

---

### 最后服务器通过：

```c
accept()
```

取出这个客户端。

同时：

```c
clinAddr
```

里会自动写入客户端地址：

例如：

```c
192.168.1.55:49832
```

所以：

---

### 真正“获得客户端地址”的函数是：

# `accept()`

不是 bind，不是 listen。

---

## 三、TCP连接建立时底层发生了什么

在 `accept()` 返回前，TCP已经完成三次握手：

---

### 第1次：

客户端 → 服务端：

```nginx
SYN
```

请求建立连接

---

### 第2次：

服务端 → 客户端：

```nginx
SYN + ACK
```

同意连接

---

### 第3次：

客户端 → 服务端：

```nginx
ACK
```

确认建立完成

---

然后：

```c
accept()
```

才返回成功。

---

## 四、两个socket必须区分

---

### lfd：

监听socket

作用：

只负责接收新连接。

---

### cfd：

通信socket

作用：

只负责和某一个客户端通信。

---

## 五、一句话理解整个过程

```text
socket() 创建通信端点
bind() 绑定服务器地址
listen() 开始监听连接
accept() 接收客户端连接并获得客户端地址
```

---

## 六、核心理解总结

---

### bind绑定的是：

> 服务器自己的地址

---

### accept得到的是：

> 客户端的地址

---

### 客户端是谁告诉服务器的？

> 是客户端自己通过 connect() 主动找上门来的。
