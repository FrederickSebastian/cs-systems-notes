1. `rm`删除文件时, `-I`：批量删除时进行一次总体确认，输出所有要被删除的文件, 经过确认后删除, 更加安全.

```
rm -rI directory/
```

2. **面试题:** 如何检查这台Linux机器的体系结构: `uname -r`
3. *ctrl + r* 检索历史命令, 搜到了以后回车自动执行
4. 更改文件的拥有者: `chown 用户 文件名`
5. `stat`查看文件状态与创建, 修改时间

## 解压与压缩

```bash
# .tar.gz / .tgz
tar -czvf archive.tar.gz 文件或目录      # 压缩
tar -xzvf archive.tar.gz                # 解压

# .tar.bz2
tar -cjvf archive.tar.bz2 文件或目录    # 压缩
tar -xjvf archive.tar.bz2               # 解压

# .tar.xz
tar -cJvf archive.tar.xz 文件或目录     # 压缩
tar -xJvf archive.tar.xz                # 解压

# .zip
zip -r archive.zip 文件或目录            # 压缩
unzip archive.zip                       # 解压
(unzip的参数-d解压到指定目录)

# .gz（通常压缩单个文件）
gzip 文件                                # 压缩，生成 文件.gz
gzip -d 文件.gz                          # 解压
# 或
gunzip 文件.gz

# .bz2（通常压缩单个文件）
bzip2 文件                               # 压缩
bzip2 -d 文件.bz2                        # 解压
# 或
bunzip2 文件.bz2

# .xz（通常压缩单个文件）
xz 文件                                  # 压缩
xz -d 文件.xz                            # 解压
# 或
unxz 文件.xz
```
