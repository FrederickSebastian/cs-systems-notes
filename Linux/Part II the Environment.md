### Chapter 12 Vim Startup

1. :buffer*s* : Check all the files opened up
2. :buffer + No. : Switch to which file
3. :bn & :bp : buffer next and buffer previous
4. :e : add new file to current editing session
5. :u : undo
6. :J : Joining lines
7. /String : search string in the entire file
8. :%s/sting/new string/g *(c)* : global search-and-replace *(with user confirmation)*
